# Control de gastos

Primera versión funcional conectada a Supabase.

Incluye:
- registro con nombre, email y contraseña
- inicio de sesión
- recuperación de contraseña
- persistencia de sesión
- perfil privado
- carga de las 12 categorías automáticas
- cierre de sesión

La app usa únicamente la URL del proyecto y la publishable key de Supabase. No contiene claves administrativas ni secretas.
